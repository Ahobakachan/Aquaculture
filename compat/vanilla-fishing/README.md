# Aquaculture Vanilla Fishing — Minecraft 1.21.1 NeoForge

## Установка

1. Оставьте **Aquaculture 2 2.7.21**, **LavaFishing 1.2.13 от Sunset** и его зависимость **Kotlin for Forge 5.10.0+**.
2. Добавьте `Aquaculture-Vanilla-Fishing-1.21.1-NeoForge-1.0.0.jar` в `mods`. На сервере установите его и на сервер, и на клиент.
3. Если установлен другой аддон `Aquaculture 2: Lava Fishing Addon` (`aq2lava`), удалите его. Правильный **LavaFishing** удалять не нужно.
4. Ловите обычной удочкой Minecraft. Farmer’s Delight остаётся установленным как обычно.

Требуется NeoForge 21.1.217+. Для Farmer’s Delight 1.3.4 требуется 21.1.219+.

## Изменения

- Ванильная удочка ловит водных рыб Aquaculture в воде и лавовых рыб LavaFishing в лаве. Исходные биомы, измерения, веса улова, добыча и сокровища сохранены.
- Сохранены ванильные зачарования, прочность удочки, опыт, событие `ItemFishedEvent`, размер/вес рыбы и достижения.
- Убраны из крафта, творческого меню, JEI/EMI и добычи удочки обоих модов, крючки, наживка (черви/пиявки), лески, поплавки, tackle box и worm farm. Старая экипировка больше не работает; ящики и фермы не взаимодействуют с игроками/воронками.
- **Minnow остаётся рыбой** и по-прежнему ловится. Его прежнее использование как наживки не требует удаления самой рыбы.
- Убраны крафты fillet knife. Рыба + нож Farmer’s Delight работают в **верстаке** через оригинальный рецепт филе Aquaculture. Сохранены число порций, учёт веса и износ ножа. Специальный бонус нептуниевого ножа (+25%) не переносится на ножи Farmer’s Delight.
- Доска Farmer’s Delight использует отдельные рецепты: этот мод не добавляет рецепты для доски.
- Результат ловли в лаве защищён от огня и получает дополнительное движение вверх; расчёт использует настоящую позицию поплавка и работает при отрицательных координатах.

Регистрации старых предметов оставлены для загрузки существующих миров. Они скрыты, отключены и не добываются; команды администратора могут по-прежнему создать такие предметы. Сам мир и инвентарь игрока автоматически не очищаются.

## Сборка и проверка

Java 21, Gradle 8.10.2:

```sh
gradle -p compat/vanilla-fishing build
gradle -p compat/vanilla-fishing/ci/integration verifyFishing
gradle -p compat/vanilla-fishing/ci/integration verifyFishing -PwithoutFD
```

В локальном отдельном каталоге вместо `compat/vanilla-fishing` используйте путь к этому каталогу.

Проверки запускают сервер с **упакованным JAR** и оригинальными Aquaculture/LavaFishing. Проверяют водные биомы, все девять лавовых видов и их биомы, естественную поклёвку, обе руки, прочность, добычу, сетевые данные поплавка, открытую/закрытую лаву, снасти, творческий поиск, воронки, ножи и повторную загрузку datapack. Ошибка загрузки сервера или отсутствие отчёта о проверках останавливают CI.

GitHub Actions сохраняет готовый JAR и отчёты в артефакты. Дополнения не включают оригинальные моды: их нужно устанавливать отдельно.

Исходники: форк Aquaculture `Ahobakachan/Aquaculture`, ветка `vanilla-fishing-1.21.1`, каталог `compat/vanilla-fishing`. Проверенный LavaFishing: `teamsunset/LavaFishing`, ветка `mc1.21.1/release`, коммит `8ec782dcc1b74197764f976fa38a71fc06c60753`.
